## 3. Architectural Scope of This Public Release
This repository distributes **Piece A (Standalone Spatial Information Tree & Classic RTS/TBS Browser)**
and the open **`SpatialGraphContract v1`** JSON/REST interface specification:
- **Zero Backend Lock-In:** Runs 100% standalone using built-in sample data or any custom JSON/YAML dataset (`--config`).
- **Codex CLI & Local LLM Ready:** Supports work-account Codex CLI (`OPSCRYER_USE_CODEX_CLI=1`), Local GPU Ollama (`OPSCRYER_OLLAMA_URL`), or optional `.env` configuration.
